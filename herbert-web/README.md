# Herbert (web)

Web port of the Unity *Herbert* heart-failure assessment game. Next.js +
[inkjs](https://github.com/y-lohse/inkjs).

```bash
npm install
npm run dev     # http://localhost:3000   (add ?debug to see ink variables)
```

* Story lives in `ink/*.ink` (compiled to `public/ink/` automatically).
* Read **[docs/DESIGN.md](docs/DESIGN.md)** for the design, architecture, ink
  conventions, known gaps and open questions.
* The Unity project one level up is untouched.
